# 🎂 Shipra's Birthday Gift Website 🎀

A dreamy, personalized, interactive digital birthday gift experience made with love for best friend **Shipra**.

---

## 🌸 Aesthetic & Features

- **Theme**: Soft baby pink (`#FFF0F5`, `#FFE4E8`), blush pink (`#FFAEC9`, `#FF85A2`), rose accents, and pure white.
- **Cute Illustrations**: Custom SVG illustrations of adorable baby pandas with blushing cheeks, sparkling eyes, birthday cakes, and balloons.
- **5 Interactive Slides**:
  1. **Slide 1 — A Birthday Surprise**: Animated panda holding a 2-tier pink birthday cake with glowing candle, floating hearts, and “Open Your Surprise 🎁” button.
  2. **Slide 2 — Our Friendship**: Two sweet pandas holding hands, sweet friendship dedication message, and 3 interactive flip cards (*My Partner in Crime*, *My Forever Gossip Buddy*, *My Favourite Person*).
  3. **Slide 3 — An Open Letter to Shipra**: Stationery letter with delicate pink dashed border, postal stamp, heartfelt letter message, and “Aww, one more surprise! 💗” button.
  4. **Slide 4 — Birthday Wishes & Happiness**: Panda with party cone hat, 5 animated wish cards (*Happiness, Success, Love, Adventure, Friendship*), and “Make a Birthday Wish 🌟” button revealing the stellar wish popup!
  5. **Slide 5 — The Final Birthday Gift**: Big chubby panda hugging a giant heart inscribed with “Besties Forever”, heartfelt closing note, and “Send You a Big Hug 🫂” button with virtual hug delivery popup!
- **Interactive Audio**: Built-in Web Audio API synthesizer playing gentle chimes, fairy sparkles, and a soft music box melody of *Happy Birthday to You* (no external MP3 required, works offline 100%).
- **Interactive Confetti & Sparkles**: Custom 60fps canvas confetti cannon and tap-anywhere heart spawner.
- **Responsive**: Beautiful on mobile phones, tablets, and desktop displays.

## 🚀 How to Open and View the Website

### Option 1: Direct Double-Click (Zero Setup)
Simply double-click `index.html` in Windows Explorer or open it in Google Chrome, Microsoft Edge, or any modern web browser.

### Option 2: Run Local Python Server
Open PowerShell in this directory and run:
```powershell
python -m http.server 8000
```
Then visit:
```
http://localhost:8000
```
